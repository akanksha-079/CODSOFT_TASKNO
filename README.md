# 💳 Credit Card Fraud Detection

## 📌 Overview

A Machine Learning project that detects fraudulent credit card transactions using Python and Scikit-learn.

## 🛠️ Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## 🤖 Models Used

* Logistic Regression
* Decision Tree
* Random Forest

## 📊 Final Results

**Random Forest + Optimized Threshold (0.20)**

* Precision: **76.19%**
* Recall: **78.32%**
* F1 Score: **77.24%**
* ROC-AUC: **99.37%**

## 🔍 Key Finding

Transaction amount (`amt`) was one of the most important features for fraud detection.
